# **Interactivity Refactor Reflection**
The refactoring process was very interesting and seeing how my code could be transformed from its original state to use objects showed me how much more efficient it could be. Instead of creating new sets of variables for each ball I had, I could just use the same object and call it again when I wanted a new one. This did lead to challenges for me when I was determining how I could keep the features I had regarding the interactions of the ball such as the growth on colliison interaction. Ultimately, I was able to get this to work by creating a separate ball interaction funciton where I defined whether the two balls I had were touching and how they should interact. This solution works but I am curious how I could, in the future, get this interaction to work universally for all balls that are in my sketch and not just the two that I defined. I would also have to learn how to create any number of balls without defining each one at a time in order to do this.
